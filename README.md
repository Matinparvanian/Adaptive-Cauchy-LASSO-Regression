# Adaptive Cauchy LASSO Regression

This repository contains the paper:

**Robust Variable Selection via Adaptive Cauchy LASSO: Guarantees and Initialization for High-Dimensional Heavy-Tailed Data**

The paper introduces **Adaptive Cauchy LASSO Regression (ACLR)**, a robust variable selection method for regression problems with heavy-tailed noise and outlier contamination. ACLR combines a Cauchy-based loss function, adaptive LASSO penalization, and Ridge–Huber initialization to improve variable selection stability, especially in high-dimensional settings.

The method is compared with Cauchy LASSO Regression, LASSO, Quantile LASSO, and Nolan–Ojeda–Revah regression using false-positive rate, false-negative rate, and prediction accuracy.
